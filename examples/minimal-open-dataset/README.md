# Minimal Open Dataset

This fixture is entirely original, hand-authored sample data created for this repository. It is dedicated to the public domain under CC0 1.0 Universal. The complete CC0 1.0 legal text is provided in this directory's `LICENSE` file.

It imitates a small subset of the JMdict XML shape only to test the parser interface. It is not copied or derived from JMdict, Wiktionary, or any commercial dictionary, and it must not be described as data from those sources.

The repository-root Apache License 2.0 covers the project's original code and documentation. It does not cover or relicense the sample data in this directory; this directory's sample data is separately released under CC0 1.0 Universal.

The corpus includes separate development and evaluation documents. Tests verify that evaluation misses are measured but never appear in the generated candidate queue.
