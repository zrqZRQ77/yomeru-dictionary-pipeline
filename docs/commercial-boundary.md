# Commercial Boundary

Yomeru is one possible consumer of this general-purpose pipeline, but no product implementation is included here.

The following are explicitly outside this repository:

- product interface, branding, copy, interaction flows, and design assets;
- frontend application runtime and learning-state modules;
- accounts, authentication, cloud synchronization, databases, and user records;
- curated commercial definitions, full Chinese datasets, course packs, exercises, and private examples;
- hidden acceptance corpora, internal approvals, review receipts, private screenshots, and release evidence;
- Vercel, Supabase, GA4, AdSense, Amazon, preview, production, deployment IDs, domains, and environment configuration;
- repository history or internal agent handoff directories from any consuming application.

The package may receive exported, license-compliant inputs through documented schemas. It must not depend on a consumer application's directory layout or runtime.
